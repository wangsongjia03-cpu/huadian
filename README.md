# 华电迎新纪念卡 H5

这是适用于 GitHub Pages 的纯静态网页版本。照片和文字只在用户浏览器中处理，不会上传服务器。

## 功能

- 点击相框或右上角按钮选择照片
- 照片自动铺满相框
- 单指拖动、双指缩放，并提供放大、缩小和复位按钮
- 最多输入 42 个字符的寄语，并切换预设文字颜色
- 生成 1228 × 2048 PNG 高清卡片
- 普通浏览器下载图片；微信浏览器长按结果图片保存
- 使用系统粗黑字体呈现近似海报标题的效果

## 发布到 GitHub Pages

1. 解压源码包。
2. 将本目录中的所有文件上传到 GitHub 仓库根目录。两张 PNG 也应与 `index.html` 保持在同一级，不要只上传 ZIP 文件。
3. 打开仓库 `Settings → Pages`。
4. 在 `Build and deployment` 中选择 `Deploy from a branch`。
5. 分支选择 `main`，目录选择 `/(root)`，然后保存。
6. 等待 GitHub Pages 部署完成后访问：

```text
https://你的用户名.github.io/仓库名/
```

页面资源均使用相对路径，可以部署在 GitHub Pages 的仓库子路径下。

## 本地预览

可以在本目录启动任意静态文件服务器。例如：

```bash
python3 -m http.server 8080
```

随后访问 `http://localhost:8080/`。

## 注意事项

- 微信 H5 无法稳定直接写入系统相册，结果页会提示用户长按图片保存。
- GitHub Pages 在部分中国大陆网络环境下可能访问较慢，适合内部测试和方案确认。
- 正式对外投放前，请确认华电 Logo、吉祥物及字体素材已获得相应使用授权。
